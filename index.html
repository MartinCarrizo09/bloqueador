Bloqueo real en el celular

Una página web no tiene permiso para bloquear apps, así que el bloqueo lo hace el propio teléfono. Seguí estos pasos una vez (5 minutos) y tildalos.

El sábado: desactivá el Modo concentración / Tiempo de inactividad y volvé a mostrar las apps.

En la PC

Programa para Windows con botón de encendido. Mientras está prendido:

  • Chrome, Edge y Brave solo abren Gemini, WhatsApp Web, Drive, Meet y Zoom.
  • YouTube, redes, streaming, juegos, compras, noticias y buscadores quedan bloqueados en todo el sistema (cualquier navegador o app).
  • Firefox, Opera, Steam, Discord y similares se cierran solos.

Se apaga solo al llegar la fecha.

Descargar para Windows

Descomprimí y abrí Modo Enfoque.bat (acepta el permiso de administrador).
